# Week 4 - Animated Startup Landing PageAn engaging and fully responsive startup landing page featuring space-themed animations, smooth transitions, and Bootstrap components.## 🚀 Project OverviewThis project showcases advanced CSS animations and responsive design techniques for a space exploration startup website. The landing page includes astronaut, rocket, and space-themed animations with smooth hover transitions and modern UI components.## ✨ Features Implemented### Task 9: CSS Keyframe Animations- **🧑‍🚀 Floating Astronaut**: Smooth floating animation with rotation- **🚀 Rocket Launch**: Dynamic rocket launch with animated trail effects- **⭐ Twinkling Stars**: Multiple star animations with varied timing- **🪐 Planet Orbit**: Rotating planet with glowing orbital ring- **🛰️ Satellite Rotation**: Spinning satellite in about section### Task 10: Navigation Hover Transitions- **Smooth background size changes** on hover- **Color transitions** with gradient effects- **Transform animations** (translateY, scale)- **Glow effects** with box-shadow- **Shimmer animations** with pseudo-elements### Task 11: Bootstrap Landing Page Components- **Responsive Grid System**: 12-column layout throughout- **Fixed Navigation Bar**: Animated navbar with scroll effects- **Image Carousel**: 3-slide carousel with fade transitions- **Service Cards**: 6 responsive service cards with hover effects- **Team Section**: 4-member team grid with social links- **Contact Form**: Floating labels with validation- **Footer**: Multi-column footer with social media links## 🛠️ Technologies Used- **HTML5**: Semantic structure and accessibility- **CSS3**: Advanced animations and transitions- **Bootstrap 5.3.0**: Grid system, components, and utilities- **Font Awesome 6.4.0**: Icons and visual elements- **Vanilla JavaScript**: Interactive functionality

## 🎨 Animation Details

### Keyframe Animations
```css
- float: 6s infinite astronaut animation
- rocketLaunch: 8s rocket launch sequence
- twinkle: 2-4s star twinkling effects
- planetRotation: 10s orbital movement
- satelliteRotation: 8s continuous spin
```

### Hover Transitions
```css
- Background: 0.4s cubic-bezier easing
- Transform: translateY(-3px) on hover
- Box-shadow: Multi-layer glow effects
- Color: Smooth gradient transitions
```

## 📱 Responsive Design

- **Desktop**: Full layout with all animations
- **Tablet (≤992px)**: Reduced animation sizes, optimized spacing
- **Mobile (≤768px)**: Single-column layout, touch-friendly navigation
- **Small Mobile (≤576px)**: Minimal animations, condensed content
